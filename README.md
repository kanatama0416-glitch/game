# ひとり商店。

会社を辞めてから開業し、事業が回り始めるまでの出来事を記録すると、自分の仕事部屋が少しずつ育っていく事業日記アプリ（プロトタイプ）。

## できること

- 出来事を「なぜ必要？ → どうやる？ → できた！」の順に進めて記録する
- 記録すると部屋にアイテムが増え、年表（MY BUSINESS HISTORY）に残る
- 退職日から「準備◯日目」、開業日から「開業◯日目」を数える
- 年金・健康保険・県の開業届・青色申告・開業届の期限と残り日数を表示する（日付は目安）
- 月ごとの売上・経費を記録し、累計売上10万円などの節目を自動で記録する
- 年表の記録と月のお金は、あとから修正・取り消しできる

## 構成

`index.html` 1ファイルで動く静的ページ。

## データの保存

ブラウザの localStorage（キー `hitori-shoten-v1`）にだけ保存する。端末間の同期はなく、ブラウザのデータを消すと記録も消える。

## 更新するとき

`index.html` の `APP_VERSION` を新しい値に変えてから push する。CSS と JS はこの値つきで読み込まれるので、スマホに古いファイルが残っていても新しいファイルを取りにいく。
